#Proiect Analiza Date SQL - Clinica Medicala

##Descriere
Proiect de interogari SQL avansate pentru generarea de rapoarte de business destinate conducerii unei clinicii medicale.

##Tehnologii si Functii Utilizate 
- SGBD: MySQL / MySQL Workbench
- Relationare: INNER JOIN, LFET JOIN
- Agregare: GROUP BY, SUM(), COUNT(), AVG()
- Filtrare: HAVING, WHERE, MONTH()
- Subqueries & Ordonare: Interogari incapsulate, ORDER BY ... DESC

##Rapoarte Incluse
1. Raport Executiv Pacienti (plati peste media generala)
2. Performanta Terapeuti (programari per terapeut, inclusiv cei care nu au avut activitate)
3. Analiza Servicii Medicale (incasari totale si volum de vanzari)
